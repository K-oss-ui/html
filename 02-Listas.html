Sobre elementos de listas

Listas são elementos importantes no HTML para organizar informações de forma estruturada.

Conhecendo as listas

Lista não ordenada (UL)

Usamos a lista não ordenada quando a ordem dos itens não importa .

  • Leite
  • Pão
  • Queijo
  • Pão
  • Frutas

Lista ordenada (OL)

Aqui. nessa estrutura, a ordem dos itens são apresentados na tela importa .

  1. Comprar ingredientes
  2. Misturara os ingredientes
  3. Colocaer no forno
  4. Comer
