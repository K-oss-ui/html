Sobre formulários

O que são formularios?

Formularios são uma das partes mais importantes do nosso HTML semântico. Ele serve para:

  • Entrada de dados
  • Interação
  • Acessibilidade
  • Validação e envio de informações

Como trabalhar com um formulario dentro do HTML

Para começarmos a trabalhar com um formulario dentro do HTML, utilizamos o elemento de < form>.

Esse elemento, representa um formulario interativo.
